Figure 5: Alert Stability - State Changes
============================================================

What it shows:
Total number of alert state transitions per run across hero scenarios.
Lower = more stable (less 'flapping' between alert states).

How to read:
- Bar height = average state changes per run
- Compare MAS (blue) vs Baseline (orange)
- Focus on extreme_dropout_50: worst-case robustness test

Interpretation:
MAS guardrails (hysteresis + debouncing + consensus) significantly reduce
alert flapping compared to baseline, especially under sensor failures.
This is critical for operational deployment (avoids alert fatigue).
