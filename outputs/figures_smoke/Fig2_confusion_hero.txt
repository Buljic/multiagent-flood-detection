Figure 2: Confusion Matrix - Hero Scenarios
============================================================

What it shows:
Aggregated confusion matrices across normal_wet, extreme_wet, extreme_dropout_50.
Rows = actual state, Columns = predicted state.

How to read:
- Top-left (TN): Correctly predicted no flood
- Top-right (FP): False alarms (predicted flood, but no flood occurred)
- Bottom-left (FN): Missed floods (predicted no flood, but flood occurred)
- Bottom-right (TP): Correctly predicted floods

Interpretation:
MAS+ML has fewer false negatives (FN) = better flood detection.
Slightly more false positives acceptable for safety-critical application.
